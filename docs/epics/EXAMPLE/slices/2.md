# Slice 2 — be: OIDC callback and revocation sweep

- Layer: be (views, tasks)
- Capability group: login, revocation
- Stories covered: S1, S2, S3
- Branch: `feature/EXAMPLE-login-be` (stacked on `feature/EXAMPLE-login-db`)
- Status: in progress

## Expected behaviour
`GET /auth/sso/callback` exchanges the code, resolves the company by email domain, refuses unverified domains with 403 `SSO-02`, and creates the session. A beat task `sweep_revoked_sso` runs every 15 minutes, asks the IdP for each linked `sub`, and marks revoked identities so the auth middleware redirects them.
